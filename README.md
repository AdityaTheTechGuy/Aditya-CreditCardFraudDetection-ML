# Credit Card Fraud Detection

I'm building a machine learning model to detect fraudulent credit card transactions as a way to learn ML fundamentals through a hands-on project.

Rather than jumping straight to a model, I want to understand the entire process — exploring the data, establishing a baseline, training different models, and figuring out what the results actually tell me.

## What I'm exploring

- Exploratory data analysis and understanding the dataset
- Building a baseline before trying more complex models
- Logistic Regression, Random Forest, and XGBoost
- Handling imbalanced datasets
- Evaluating models using precision, recall, and PR-AUC
- Experimenting with decision thresholds and analyzing mistakes

## Dataset

I'm using the [Credit Card Fraud Detection dataset on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).

It contains 284,807 transactions, including 492 fraudulent ones. The dataset is highly imbalanced, which makes it an interesting problem to work on.

The features are mostly anonymized, so the focus is on learning classification and evaluation techniques rather than interpreting actual customer spending behavior.

## Tech Stack

Python · pandas · NumPy · scikit-learn · Matplotlib · XGBoost
